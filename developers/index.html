Build with your health data

VitaVault exports Apple Health data in two formats: CSV (for spreadsheets) and JSON (for code and AI tools). The export toolkit is open source.

Two export formats

Each export gives you the same Apple Health samples in a different shape. Exports are unlimited for everyone. Free exports cover 5 metrics for the last 7 days; Premium covers every metric and your full history.

1. JSON (for developers and AI tools)

One record per Apple Health sample, with its type, value, unit, start and end time, and source. Easy to parse in any language. Trimmed here: the real file also carries device and app details, and every record in the range.

2. CSV (for spreadsheets)

Opens directly in Excel, Google Sheets, or Numbers. One row per Apple Health sample, with the same fields as the JSON records. Filter by type to chart any metric over time.

Upload your export to an AI tool

These tools don't connect to VitaVault. You upload your JSON or CSV file, or paste it in, and ask. Here are some prompts to get started.

To get the file out of VitaVault, tap Share Export after Export Now and save it to Files or send it to another app.

ChatGPT

Paste or attach your export file and ask for actionable health recommendations.

Prompt
Analyze my health trends and give me 3 actionable recommendations.

Claude

Attach your JSON file and ask for a comprehensive health report.

Prompt
Review this JSON and create a comprehensive health report with risks, trends, and next steps.

Gemini

Attach your export file in Google AI Studio and ask for personalized insights.

Prompt
Summarize my health metrics, identify outliers, and suggest a one-week improvement plan.

Your Own App

Parse JSON/CSV in Python, JavaScript, or any language. Build dashboards, alerts, or integrations.

JavaScript
const steps = data.records
  .filter(r => r.type === "stepCount")
  .reduce((sum, r) => sum + (r.value ?? 0), 0);
console.log(`Steps in this export: ${steps}`);

VitaVault stores your health data on your iPhone, and there is no public API yet. The one exception is AI agent sync through VitaVault Cloud, which is off unless you turn it on: your agent then reads your synced data from our server with a connection key unique to your device. Today that works with the OpenClaw skill. Otherwise, health data is sent only when you use an AI feature or scan. Medications, lab results, journal and check-ins can also sync through your own iCloud (see the Privacy Policy).
